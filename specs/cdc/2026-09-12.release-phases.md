# Prévisualisation, préparation à la publication et clôture

Le contrôle de construction exigeait le CDC global terminé, incluant son compte rendu après publication. Les phases sont maintenant distinctes et aucune exigence fonctionnelle n’est supprimée.

- `npm run build` contrôle les sources et exécute tous les tests avant de créer un artefact de test.
- `npm run check:release` impose la préparation des 33 chapitres et les scénarios préalables. Le chapitre 32 possède une preuve `preDeployment` distincte. LIV-06 est le seul scénario qui attend la publication.
- `npm run check:cdc` exige la clôture entière, avec LIV-06 réussi, le chapitre 32 final et le relevé du commit et de l’URL effectivement publiés.
- GitHub présente les résultats techniques et la préparation séparément. Le contrôle de fusion existant « Source and tests » dépend des deux ; échec, annulation ou absence de réussite interdit la fusion.
- Le constructeur refuse également la production si la préparation n’est pas validée. Le manifeste reste `implementation-in-progress`, sans preuves fictives.

Les prévisualisations ne reprennent plus la configuration Supabase de production. Sans base de test distincte et clé publique explicites, les espaces personnels affichent un état indisponible explicite dans l’artefact. La découverte fictive demeure consultable. Les sources applicatives et photographies ne sont pas remplacées. Les vérifications connectées continuent en Docker local.

Validation locale : installation propre, **186 tests réussis** et construction de **203 fichiers statiques**. Les nouveaux tests couvrent les preuves absentes, les chapitres et scénarios retirés, la séparation avant/après publication, le rejet des clés privilégiées et de la base de production en prévisualisation, ainsi que le refus réel du constructeur de production pour un CDC incomplet. Les preuves de publication restent en attente.

Référence de configuration : [variables système Vercel](https://vercel.com/docs/environment-variables/system-environment-variables). Aucun contrôle de préparation n’est retiré des règles de fusion et aucune publication en production n’est autorisée par cette correction.
